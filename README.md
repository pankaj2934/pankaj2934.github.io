## 👨‍👩‍👧 For grown-ups

- 📱 **Works everywhere.** Every page fits a phone, a tablet or a laptop.
- 🔒 **Private.** Nothing is uploaded. Scores stay in your own browser.
- ✏️ **Set your own problems.** Many games let you type in your own numbers: look for **"Mine"** or **"My numbers"**.
- 🔇 **Sensory friendly.** In HCF Tricks, sound and animations start **off**. Turn them on with the buttons at the top.

---

## 🛠️ Add a new game

1. Add a self-contained `your-game.html` to this folder.
2. Add a row for it to the right section of this README (and to **New and featured** if it's new).
3. Commit and push. GitHub Pages publishes it at `https://pankaj2934.github.io/your-game.html`.
