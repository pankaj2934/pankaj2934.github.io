Your mission 🎯

Make a fraction as simple as it can be. Divide the top and the bottom by the same number, again and again, until no number (except 1) can divide both.

13456 ÷2 → 6728

Your clues are the divisibility tricks below. They tell you if a big number can be divided, without doing the whole division!

🔎 Number Detective

Type any number to see which clues it passes.

The clues

÷2

Even ending

Last digit is 0, 2, 4, 6 or 8? Then it divides by 2.

134 → ends in 4
67 → ends in 7

Keep dividing by 2 until one number turns odd!

÷3

Digit sum

Add up all the digits. If the total is in the 3× table, the number divides by 3.

249 → 2+4+9 = 15
67 → 6+7 = 13

Works for ANY size of number, even 1,000,002!

÷4

Last two digits

Look only at the last two digits. If they divide by 4, the whole number does.

1,316 → 16 = 4 × 4
134 → 34 isn't in the 4× table

Why? 100 always divides by 4, so only the end matters.

÷5

0 or 5 ending

Ends in 0 or 5? Then it divides by 5.

245 → ends in 5
134 → ends in 4

Ends in 0? It passes ÷2 AND ÷5. That means ÷10!

÷6

Double check

Must pass both the ÷2 clue and the ÷3 clue.

114 → even, 1+1+4 = 6
134 → even, but 1+3+4 = 8

Because 6 = 2 × 3.

÷9

Digit sum again

Add up the digits. If the total is in the 9× table, the number divides by 9.

729 → 7+2+9 = 18
134 → 1+3+4 = 8

If it passes ÷9, it passes ÷3 too.

÷10

Ends in 0

Ends in 0? Then it divides by 10.

560 → ends in 0
56 → ends in 6

Just knock off the 0: 560 ÷ 10 = 56.

★ Expert
÷7

Chop & double

Chop off the last digit and double it. Take that away from what's left. If the answer is in the 7× table (or 0), it divides by 7.

343 → 34 − 6 = 28
134 → 13 − 8 = 5

For numbers up to 70, just use your 7× table.

★ Expert
÷11

Zig-zag

Go minus, plus, minus across the digits: first − second + third… Get 0 or an 11× table number? It divides by 11.

286 → 2 − 8 + 6 = 0
134 → 1 − 3 + 4 = 2

2-digit numbers: both digits the same, like 44 or 77.

🧠 Big trick
🧩

Smart trick

Break the smaller number into prime pieces. Only those pieces can be shared with the other number!

67/28: 28 = 2 × 2 × 7

So for 67/28 you only need to test 2 and 7. Neither divides 67, so you're done!

🗺️ The Detective's Plan

  1. Both even? Divide by 2. Repeat until one is odd.
  2. Both digit sums in the 3× table? Divide by 3. Repeat.
  3. Both end in 0 or 5? Divide by 5. Repeat.
  4. Smart trick: break the smaller number into primes and test only those (like 7, 11, 13…).
  5. Nothing divides both? Case closed. It's in simplest form! 🎉

🏅 Fancy word: all the numbers you divided by, multiplied together, make the Greatest Common Factor (GCF): the biggest number that divides both. For 134/56 it's 2.
